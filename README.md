# ARARA Factory

Локальный генератор вертикальных Reels из готового видео, библиотеки brainrot-вставок и шаблонных субтитров.

## MVP

1. Положить вертикальное видео в `input/`.
2. Положить вставки в `brainrot/`.
3. Установить проект: `pip install -e .`
4. Запустить: `arara-factory generate input/video.mp4`
5. Получить варианты в `output/`.

## План пайплайна

- анализ аудио и пауз;
- распознавание команд `arara / rara / rarara / ararara`;
- нарезка и вставки по правилам;
- ASS-субтитры в стиле CapCut;
- FFmpeg-рендер нескольких вариантов;
- локальная очередь предпросмотра и публикации.

## Статус

Сейчас заложен каркас проекта, CLI, конфиг команд и первый шаблон субтитров. Следующий модуль — реальный FFmpeg-рендерер.
